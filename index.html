Frequently asked questions

What is TinyWow Now?

TinyWow Now is a free website with image, PDF, video, file and text tools. Every tool runs in your browser, so your files are processed on your own device and are not uploaded.

How do I use a tool?

Open the tool you need, add your file by dragging it in or clicking Choose files, set any options, and download the result. There is nothing to install and no account to create. The image compressor on this page is one of the tools; the full version has more options.

Are my files uploaded to a server?

No. The tools run in your browser. Some tools download a helper library the first time you use them, but your files are never sent to us or anyone else.

Is TinyWow Now really free?

Yes. There is no sign-up, no watermark and no usage limit.

Which tools are available?

Over 50 tools: an image compressor, resizer and converter; PDF merge, split, compress, sign and convert tools; video compress, trim, convert and merge tools; ZIP, spreadsheet and JSON tools; and text utilities.

Does it work on my phone?

Yes. The site works in modern phone browsers. Video tools can be slow on older phones because they run on the device.
